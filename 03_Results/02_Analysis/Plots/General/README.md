# General — Quality Control and Differential Expression Summary Plots

This directory contains quality control (QC) visualizations and differential expression summary plots generated during the main analysis pipeline. These figures assess sample quality, replicate consistency, and overall data structure prior to downstream GSEA and trajectory analyses.

## File inventory

| File | Description |
|---|---|
| `sample_correlation_heatmap_ordered.pdf` | Sample-to-sample Pearson correlation matrix; samples ordered by timepoint then genotype |
| `MDS_plot.pdf` | Multi-dimensional scaling plot based on leading log-fold changes |
| `PCA_plot.pdf` | Principal component analysis of log-CPM expression values |
| `DE_gene_counts.pdf` | Bar chart of differentially expressed gene counts per contrast (FDR < 0.05, |log2FC| > 1) |
| `DE_gene_counts_FDR_0.1.pdf` | Same as above with relaxed FDR 0.1 threshold |
| `UpSet_plot_all_contrasts.pdf` | UpSet plot showing intersection sizes of significant-gene lists across all 9 contrasts |

## Reading guide

**Sample correlation heatmap**: Color scale from yellow (high correlation, r → 1) to brown (lower correlation). Samples are annotated by genotype (green = Control, orange = G32A, purple = R403C) and timepoint (pink = D35, green = D65). Expect high within-group correlation (r > 0.95) and visible clustering by timepoint as the dominant source of variation.

**MDS plot**: X-axis = leading log-fold change dimension 1 (primary variation source, ~32%); Y-axis = dimension 2. Each point is one sample. Colors = genotype; shapes = timepoint (circle = D35, triangle = D65). Samples that cluster together have similar global expression profiles.

**PCA plot**: X-axis = PC1 (~35% variance, driven by timepoint); Y-axis = PC2 (~15% variance). Same color/shape encoding as MDS. The two plots provide complementary distance metrics.

**DE gene counts**: Bars split by direction (orange = upregulated, blue = downregulated). Counts reflect genes meeting both fold-change and FDR thresholds. Time effects (D65 vs D35) typically yield more DEGs than mutation-vs-control contrasts; interaction terms (Maturation_G32A/R403C_specific) yield fewer.

**UpSet plots**: Vertical bars are intersection sizes; horizontal bars are total genes per contrast. The largest intersections typically involve shared DEGs between the two mutations or between timepoints, revealing which gene sets are mutation-independent vs genotype-specific.
