## Reading guide

**Heatmaps (Fig1, Fig2, Fig3b, Fig4)**: Color = NES (blue = downregulated, red/orange = upregulated). Rows = pathways grouped by pattern (Compensation, Sign_reversal, etc.) or semantic category. Columns = trajectory stages (Early / TrajDev / Late) for each mutation. Colorblind-safe Blue-White-Red palette (viridis/RdBu_r family).

**UpSet plot (Fig1b, Supp Fig S6)**: Vertical bars = intersection sizes between ribosome gene pools (cytoplasmic, presynaptic, postsynaptic, mitochondrial). Horizontal bars = set sizes. Connected dots below indicate which sets are intersected. Key finding: all 70 genes of the SynGO synaptic-ribosome set are members of the curated cytoplasmic ribosomal gene set (Jaccard = 0.574).

**Pattern bar chart (Fig3)**: X-axis = pattern type; Y-axis = pathway count; colors distinguish G32A (blue/green) vs R403C (orange/red); faceted by database.

**Color palette reference**: Documents mutation colors (Control = teal, G32A = orange, R403C = purple), NES color scales, and pattern category colors used consistently across all figures.

## Manuscript supplementary caption (Supp Fig S6, `Fig1b_Ribosome_Gene_Overlap_UpSet.pdf`)

**Gene-pool overlaps among the cytoplasmic, synaptic, and mitochondrial ribosomal proteomes.** UpSet plot quantifying set intersections between the curated cytoplasmic ribosomal gene set (GO:CC cytosolic ribosome + GO:MF structural constituent of ribosome), the SynGO synaptic-ribosome sets (presynaptic ribosome and postsynaptic ribosome), and the mitochondrial ribosomal gene set (MitoCarta `Mitochondrial_ribosome` + GO:CC mitochondrial large/small ribosomal subunit). Vertical bars = intersection sizes; horizontal bars on the left = total set sizes per pool; connected dots below each vertical bar indicate the participating sets. The panel documents the gene-set containment that underwrites the manuscript's structural-vs-biogenesis interpretation: all 70 SynGO postsynaptic-ribosome genes are members of the curated cytoplasmic ribosomal proteome (Jaccard with GO:CC cytosolic ribosome = 0.574), establishing the synaptic-ribosome collapse documented in Fig 5F and the running-sum panels in `../SynGO_running_sum_normalised/` as the amplitude extreme of a broader cytoplasmic structural-ribosome program rather than a synapse-specific phenomenon. The mitochondrial-ribosomal pool is disjoint from the cytoplasmic and synaptic pools, supporting the dual-arm interpretation of the translation paradox (mitochondrial compensation vs cytoplasmic / synaptic collapse).
