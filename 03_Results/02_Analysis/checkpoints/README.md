# 03_Results/02_Analysis/checkpoints — cached R objects for pipeline reproducibility

## Overview

This directory stores serialized R objects (RDS format) that cache the output of computationally expensive pipeline steps. Downstream scripts load these files instead of re-running DE fitting, GSEA, or GSVA from raw counts. The system uses a `load_or_compute()` helper throughout `02_Analysis/1.1.main_pipeline.R`: if a checkpoint file exists and `force_recompute = FALSE`, the cached object is returned without re-computation. Total on-disk size: ~147 MB.

**Primary generating script:** `02_Analysis/1.1.main_pipeline.R`

## Reading Guide

All files are R `readRDS()` objects. Key access patterns:

- `model_objects.rds`: `$fit` (MArrayLM after eBayes), `$v` (voom EList), `$DGE` (DGEList), `$contrasts` (contrast matrix), `$de_results` (decideTests matrix).
- `contrast_tables.rds`: named list of 9 data frames keyed by contrast name (e.g., `$G32A_vs_Ctrl_D35`); each has columns logFC, AveExpr, t, P.Value, adj.P.Val, B; gene symbols are row names.
- `all_gsea_results.rds`: nested list — first key is contrast name, second is database name (hallmark, kegg, reactome, gobp, gocc, gomf, wiki, canon, cgp, tf); each leaf is a clusterProfiler `gseaResult` S4 object; access results via `@result`.
- `qc_variables.rds`: `$ordered_samples` (character vector), `$annot` (genotype/days data frame), `$ann_colors` (palette list), `$logCPM` (log2-CPM expression matrix for all 25 samples).
- `gsva_all_pathways.rds`: matrix or list of per-sample GSVA scores for all pathways; consumed by `02_Analysis/1.6.gsva_analysis.R` to produce `master_gsva_all_table.csv`.

**Forcing recomputation:** Set `force_recompute = TRUE` in `02_Analysis/1.1.main_pipeline.R`, or delete the specific `.rds` file and re-run the relevant script.
