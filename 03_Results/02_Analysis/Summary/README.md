# 03_Results/02_Analysis/Summary — per-contrast DEG count summary

## Overview

This directory holds the concise per-contrast DEG count table written by the main R pipeline. It provides the quick-reference up/down counts used in main-text and figure legends to characterise the scale of the transcriptional response. Additional threshold-stratified counts (FDR 0.5/0.1/0.05/0.01) are in the root-level `DE_threshold_summary.csv` generated by `02_Analysis/revision/supplements/Supp3.analyze_de_thresholds.R`.

**Generating script:** `02_Analysis/1.1.main_pipeline.R`

---

## File Inventory

| File | Description |
|------|-------------|
| `DE_summary.csv` | Up/Down DEG counts (FDR < 0.05, \|logFC\| > 1) for all 9 contrasts |

---

## Column Dictionary: DE_summary.csv

| Column | Description |
|--------|-------------|
| `Contrast` | Limma-voom contrast name (e.g., `G32A_vs_Ctrl_D35`, `Maturation_G32A_specific`) |
| `Up` | Number of significantly upregulated genes (FDR < 0.05 and log2FC > 1) |
| `Down` | Number of significantly downregulated genes (FDR < 0.05 and log2FC < −1) |

DEG counts for bar charts and UpSet plots use FDR < 0.05 only (no FC cutoff); these stricter counts (with FC threshold) are reported here for a concise landscape summary. For the full gene-level statistics at all thresholds, use `DE_results/` and `../DE_threshold_summary.csv`.
